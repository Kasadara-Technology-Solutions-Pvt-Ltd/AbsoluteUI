# Contributing to AbsoluteUI

AbsoluteUI is Kasadara Technology Solutions Pvt Ltd's contribution to the open-source community, licensed under the [Apache License 2.0](LICENSE). Thank you for your interest in it.

## Code contributions are not accepted

AbsoluteUI is developed by Kasadara. This repository receives a snapshot of the source with every release; it is not where development happens, so pull requests cannot be merged and are closed. The Apache License 2.0 still lets you fork, modify, and redistribute the code under its terms.

## What helps

| You want to | Do this |
|---|---|
| Report a bug | Open an issue with the **Bug report** form. Include the package and version, the browser, and the smallest steps that reproduce it. |
| Ask for a feature | Open an issue with the **Feature request** form. Describe the problem you are solving, not only the solution. |
| Report a security vulnerability | **Do not open an issue.** Use the **Report a vulnerability** button on the [Security tab](https://github.com/Kasadara-Technology-Solutions-Pvt-Ltd/AbsoluteUI/security) or email security@kasadara.com, as described in the [Security Policy](SECURITY.md). |
| Fix the documentation | Open an issue with the page link and the correction. |
| Ask how to use a component | Read the [documentation](https://aui.kasadara.com/docs/) first; if it does not answer the question, open an issue. |

Search the existing issues before opening a new one. Do not include personal data, credentials, or production data in issues.

## How issues are handled

Maintainers triage new issues, label them, and may ask for more detail. Fixes ship in the next release and appear here with the next source snapshot. An issue that cannot be reproduced, or that is out of scope, is closed with a short explanation.

## Code of conduct

Everyone who takes part in this project's spaces follows the [Code of Conduct](CODE_OF_CONDUCT.md).
